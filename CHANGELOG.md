# Changelog

## 0.2.0

- **Deploy light.** A lamp strip under the bench: grey before any deploy, pulsing amber while one runs (with the current step), green or red when it ends, plus a toast. Driven by the new `ooze-deploy` command, which wraps any deploy script (`ooze-deploy run "Site" -- ./deploy.sh`) or can be called step by step.
- The installer links `ooze-deploy` next to `ooze-xfer`.

## 0.1.0

- First release: live rsync progress bench, lab log, swappable mascot pack.
